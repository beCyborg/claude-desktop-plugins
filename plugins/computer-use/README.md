# computer-use — рабочий стол macOS с дисциплиной расхода токенов

Claude управляет native-приложениями macOS (Finder, Заметки, Календарь, Карты, Системные настройки, любой сторонний софт без API) через **встроенный** в Claude Code MCP-сервер `computer-use`.

Сам сервер уже входит в Claude Code — плагин его не ставит. Плагин добавляет **скилл-дисциплину**, без которой computer-use быстро сжигает контекст:

- скриншот — самая дорогая операция (~1–1.8K токенов за кадр, история пере-отправляется каждой итерацией: 18 кадров ≈ 279K токенов) → скилл учит, когда кадр нужен, а когда его заменяют текстовые каналы (буфер обмена, файлы), `zoom`, `list_granted_applications` или проверка по живому состоянию;
- `computer_batch` — цепочки действий одним вызовом вместо петли «скриншот → клик → скриншот», с хвостовым кадром, который верифицирует итог и становится базой координат следующего вызова;
- надёжность действий: `type` проваливается молча при потере фокуса, кириллица через буфер, клавиатура для мелких целей, невидимые слои поверх цели — правила, снятые с боевых прогонов и официальных best practices Anthropic;
- диагностика: TCC-гранты хост-процесса, машинный лок «одна сессия», чёрный кадр = права, чек-лист «тулов не видно»;
- `references/app-recipes.md` — накопитель рецептов под конкретные приложения (deep-links Системных настроек, каналы извлечения результата, ловушки чат-приложений);
- таблица валидных сигнатур инструментов — меньше потерянных ходов на ошибках параметров;
- иерархия поверхностей: API/MCP/CLI → браузер → пиксели. computer-use — последнее средство, а не первый ход.

## Prerequisites

- **macOS** (computer-use в Claude Code есть только на Mac).
- **План Pro или Max** (research preview; на Team/Enterprise недоступен).
- Интерактивная сессия Claude Code (в headless `-p` не работает).

## Включение (один раз на проект)

1. В сессии Claude Code выполните `/mcp`.
2. Найдите в списке `computer-use` → **Enable**.
3. При первом использовании macOS попросит два разрешения — выдайте оба:
   - **Accessibility** (Универсальный доступ) — клики, ввод, прокрутка;
   - **Screen Recording** (Запись экрана) — скриншоты.

## Проверка

Попросите: «сделай скриншот рабочего стола и скажи, какие приложения открыты». Claude запросит доступ (`request_access`), снимет кадр и опишет экран.

## Что не сюда

- Веб и залогиненные сайты → плагин **browser** (Playwright, DOM-aware — дешевле и надёжнее пикселей).
- Electron-приложения (Slack, Obsidian, VS Code, Discord) → их MCP/CLI, не пиксели.
- Терминал → Bash; файлы проекта → Read/Write/Edit.
- У приложения есть свой MCP или CLI → используйте его.
