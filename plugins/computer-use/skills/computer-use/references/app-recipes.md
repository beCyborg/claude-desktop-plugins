# Рецепты приложений — computer-use

Накопитель проверенных маршрутов под конкретные приложения. Читается перед новой задачей в приложении; после успешного прогона нового приложения — дописать рецепт.

## Формат рецепта

- Шаги — **описаниями**, не координатами: путь по меню («Файл → Экспортировать как PDF…»), горячая клавиша, подпись/расположение цели («синяя кнопка Save в правом нижнем углу»). Координаты не записывать: скриншот даунскейлится под текущий экран, числа невоспроизводимы между сессиями и мониторами.
- Рецепт — ориентир, не строгий реплей: ищи эквивалентный элемент в текущем интерфейсе; расхождение с рецептом — сигнал перепроверить, а не слепо продолжать.
- Фиксируй и тупики: «через меню X не работает, потому что Y» экономит будущий прогон.

## Извлечение результата — каналы по надёжности

1. Кнопка «Копировать» в приложении → `read_clipboard` (грант `clipboardRead`). Объём сверить: `pbpaste | wc -m` — вдруг скопировалась только видимая страница.
2. ⌘A ⌘C в поле/документе → `read_clipboard`.
3. «Сохранить/экспортировать в файл» → прочитать файл через Bash.
4. Крайний случай — свежие артефакты по mtime в песочнице приложения: `find ~/Library/Containers/<bundle>/Data -newer /tmp/marker -type f` или `stat -f '%m %N' … | sort -nr | head`. Не `find ~` по всему дому — медленно и вытаскивает чужое приватное.

Чтение с экрана скриншотами — последний канал, только когда текстовых путей нет.

## Системные настройки (System Settings)

Deep-link одной командой вместо навигации по панелям:

```bash
open "x-apple.systempreferences:com.apple.preference.security?Privacy_ScreenCapture"
open "x-apple.systempreferences:com.apple.preference.security?Privacy_Accessibility"
```

Схема `x-apple.systempreferences:<bundle>?<anchor>` общая; якоря проверять на текущей версии macOS. Ценно вдвойне: System Settings — приложение класса «может менять системные настройки», каждый лишний клик там дорог.

## Заметки (Notes)

- Запуск: `open_application(app="Заметки")`. Проверено (2026-09-01, macOS 27 beta): без открытого окна ⌘N — тихий no-op, а следующий `type` уходит «в воздух». Порядок: ⌘0 (главное окно) → чекпойнт-кадр → ⌘N → ввод.
- Первая строка становится заголовком; тело — со второй строки. Многострочный текст — одним `type` (или через буфер, если длинный/кириллица глючит: `write_clipboard` → ⌘V).
- Верификация без скриншота: `osascript -e 'tell application "Notes" to get name of notes 1'` (заголовок последней заметки) — живое состояние вместо кадра.

## Чат-подобные приложения (мессенджеры, AI-клиенты)

- Сбившийся диалог/сессию не продолжать — ошибочный контекст портит последующие ответы; начинай чистый чат.
- Уже открыто окно/диалог по теме → продолжай в нём, не создавай новое: снимает целую фазу навигации.
- Точки входа, меняющие состояние (новый чат/новая задача в сайдбаре), — горячей клавишей, не кликом: соседние пункты тихо подменяют режим.
